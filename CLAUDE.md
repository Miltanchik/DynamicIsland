## Правило автоматической синхронизации с GitHub (только папка `dynamic_island`)

Git-репозиторий (`https://github.com/Miltanchik/DynamicIsland.git`) привязан **строго к папке `c:\Users\Miltan\.vscode\projectx\dynamic_island`** (а не ко всей папке `projectx`).
После каждого завершённого изменения в файлах `dynamic_island` — а также в начале задачи, если в `dynamic_island` есть незакоммиченные правки — ты обязан автоматически фиксировать и отправлять изменения в GitHub, выполняя команды Git внутри `c:\Users\Miltan\.vscode\projectx\dynamic_island`.

### Порядок действий:
1. Перейди в `c:\Users\Miltan\.vscode\projectx\dynamic_island` и выполни `git status`. Если изменений нет — пропусти шаг.
2. **Проверка безопасности:** убедись, что среди изменённых файлов нет секретов (`.env`, API-ключей, токенов, паролей, приватных ключей) и тяжёлых/временных папок (`node_modules`, `__pycache__`, кэш). Если такие файлы попали в список — НЕ добавляй их в коммит, добавь их в `.gitignore` и предупреди меня.
3. Подготовь файлы к коммиту (`git add -A` для безопасных изменений).
4. Сделай коммит с коротким, понятным описанием сути правок в формате Conventional Commits (например: `feat: добавить форму входа`, `fix: исправить расчёт скидки`, `refactor: упростить обработчик API`).
5. Отправь изменения в текущую ветку командой `git push`.
6. **Обработка ошибок:**
   - Если `git push` отклонён из-за новых коммитов в удалённом репозитории, выполни `git pull --rebase` и повтори `git push`.
   - Если возник конфликт слияния — остановись, не применяй принудительные флаги и сообщи мне.
   - Никогда не используй `git push --force`, если я не попросил об этом явно.
7. В конце своего ответа одной строкой укажи хэш и текст сделанного коммита (например: `GitHub: [a1b2c3d] fix: исправить расчёт скидки`).
